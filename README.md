# Deutsch Meistern — A1 to B1 German Guide

A complete, self-contained study guide for learning German from zero to B1 — with a specific focus on passing the **Berlin Sprachtest** (telc Deutsch B1 / Goethe-Zertifikat B1).

---

## What's Inside

The guide is a single rich HTML file (`german-roadmap-berlin.html`) covering:

| Section | What you get |
|---|---|
| **Overview** | 12-month roadmap with hour estimates per level |
| **A1 — Foundation** | Alphabet, pronunciation, greetings, articles, cases, present tense, family & numbers |
| **A2 — Building** | Perfekt, modal verbs, all 4 cases, prepositions, subordinate clauses |
| **B1 — Intermediate** | Konjunktiv II, passive voice, relative clauses, opinion phrases, B1 dialogues |
| **Grammar Hub** | Separable verbs, adjective endings, comparatives, Präteritum, word order |
| **Vocab Hub** | 800+ words by theme + 200+ essential sentences + B1 topic vocabulary |
| **Berlin Exam Prep** | Full exam structure, reading/writing/speaking/listening strategies, model answers |
| **Study Plan** | Month-by-month schedule with daily targets |
| **Interactive Quiz** | Self-test your A1–B1 grammar knowledge in the browser |

---

## How to Use

1. **Open** `german-roadmap-berlin.html` in any browser — no server or internet needed
2. **Use the sticky nav bar** to jump between sections
3. **Follow the roadmap** in order (A1 → A2 → B1) or jump to any topic you need
4. **Practice with the quiz** section to test your progress
5. **Berlin Exam** section is essential if you're preparing for telc/Goethe B1

---

## Learning Path

```
Month 1–2    A1 Breakthrough     ~100 hours   Basic communication
Month 3–5    A2 Waystage         ~200 hours   Past tense, all 4 cases
Month 6–10   B1 Intermediate     ~350 hours   Complex grammar, opinions
Month 11–12  Exam Preparation               Mock exams + final polish
```

---

## Key Features

- **Berlin-focused context** — vocab and dialogues for daily life in Berlin (Bürgeramt, BVG, WG-hunting, Kiez)
- **All 4 cases covered** — Nominativ, Akkusativ, Dativ, Genitiv with clear tables
- **Exam-ready** — model writing tasks, speaking scripts, listening strategies
- **Common mistakes table** — 10 frequent errors with wrong/correct examples and explanations
- **Interactive quiz** — JavaScript quiz covering grammar across all three levels
- **No dependencies** — single HTML file, works offline

---

## Target Exam

The guide is specifically calibrated for the **Berlin Sprachtest**:

- `telc Deutsch B1` — required for permanent residency (Niederlassungserlaubnis)
- `Goethe-Zertifikat B1` — alternative accepted at most Ausländerbehörden
- Covers all four skills: **Hören · Lesen · Schreiben · Sprechen**
